## METHODOLOGY NOTES

- **Phase 1 sources:** PitchBook name-by-name searches, ForgePoint/Nyca/Centana portfolio pages, web sub-vertical deep dives (bot management, behavioral biometrics, crypto AML, synthetic ID, chargeback automation, document verification, B2B payment fraud), Forrester Wave reports (bot management, AML, IDV), Gartner Magic Quadrant (IDV), Datos Insights Matrix (fraud/AML), CB Insights fraud technology report, competitor maps
- **Phase 2:** Notion Deals DB semantic query (collection ID: `4d07e92f10ca472e9fa358dfaa4353b3`) + name-level spot checks for highest-priority candidates
- **Phase 3:** LinkedIn headcount via Tracxn/PitchBook/ZoomInfo cross-reference; ownership confirmed via web/PitchBook; last round and lead investors from Crunchbase/PitchBook/press releases
- **Headcount cutoffs:** ≥90 LinkedIn employees (floor) and ≤600 (ceiling); borderline cases within ±2% flagged rather than hard-excluded
- **PE ownership:** Permitted (Great Hill, Nordic Capital, Corsair, Marlin, Summa, Permira, WestCap, Goldman Sachs MBD, STG all treated as eligible)
- **"Last Round" for PE-backed acquisitions:** Reflects the PE acquisition event as the most material recent capital event; prior VC rounds noted in one-sentence description where relevant
